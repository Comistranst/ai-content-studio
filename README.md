# AI Content Studio

> A lightweight AI content creation tool built with FastAPI and JavaScript.

## Project Overview

AI Content Studio 是一个帮助内容创作者快速生成营销文案的 AI Web 应用。

第一版（v0.1）目标：

- 根据产品主题生成营销文案
- 支持不同平台
- 保存历史记录
- 调用 AI 模型生成内容
