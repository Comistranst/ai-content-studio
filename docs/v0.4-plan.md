# v0.4 开发计划：内容项目与版本管理

## 目标

将 AI Content Studio 从一次性文案生成工具，升级为可持续管理内容创作过程的 AI 内容工作台。

用户可以创建内容项目，在同一个项目内保存初稿、优化稿和手动修改稿，并选择最终发布版本。

## 用户流程

1. 用户创建一个内容项目。
2. 用户填写主题、平台、受众、风格和长度。
3. 系统调用 AI 生成初稿。
4. 系统将初稿保存为该项目的第一个版本。
5. 用户可以对某个版本进行优化。
6. 每次优化结果都保存为新的版本，不覆盖原版本。
7. 用户可以查看历史版本。
8. 用户可以将某个版本设为最终稿。
9. 用户可以复制最终稿或继续编辑。

## 核心数据模型

### projects

用于保存一篇内容的基本信息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | integer | 项目 ID |
| topic | string | 内容主题 |
| platform | string | 发布平台 |
| audience | string | 目标受众 |
| style | string | 文案风格 |
| length | string | 文案长度 |
| status | string | drafting 或 final |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### content_versions

用于保存项目内的每一个文案版本。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | integer | 版本 ID |
| project_id | integer | 所属项目 ID |
| source_type | string | generated、optimized、manual |
| optimization_goal | string | 优化目标，可为空 |
| title | string | 文案标题 |
| body | text | 文案正文 |
| hashtags_json | text | 标签 JSON |
| is_final | boolean | 是否为最终稿 |
| created_at | datetime | 创建时间 |

## 第一阶段功能

- 新建内容项目
- 获取项目列表
- 获取单个项目详情
- 生成文案后自动保存为初稿版本
- 优化文案后自动保存为新版本
- 展示项目内版本列表
- 将某个版本设为最终稿
- 删除某个版本

## API 规划

| 方法 | 地址 | 功能 |
| --- | --- | --- |
| POST | /api/projects | 创建项目 |
| GET | /api/projects | 获取项目列表 |
| GET | /api/projects/{project_id} | 获取项目及版本 |
| POST | /api/projects/{project_id}/versions | 新建版本 |
| PATCH | /api/versions/{version_id}/final | 设为最终稿 |
| DELETE | /api/versions/{version_id} | 删除版本 |

## 完成标准

- 用户能创建并查看多个内容项目。
- 每个项目能保存多个生成或优化版本。
- 设为最终稿后，同一项目只有一个最终版本。
- 刷新网页后，项目和版本仍能从 SQLite 正确读取。
- 现有生成、优化和历史记录功能不被破坏。
